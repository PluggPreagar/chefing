Ablaufdiagramm — drei Layout-Optionen

Dummy-Vergleich mit denselben acht Beispielschritten (Gugelhupf). Fenster schmaler ziehen, um den Umbruch zu testen. Bei Option C: Icon anklicken → Detailzeile unten wird markiert.

Option A — Flexbox-Icon-Kette, Skizzenbuch-Schrift

Kein SVG, kein Rahmen, umbricht automatisch, Text in Skizzenbuch-Font.

Option B — SVG, mehrzeilig, ohne Box

SVG-Rendering bleibt, aber ohne rect, mit Zeilenumbruch bei Bedarf.

Option C — Reine Icon-Kette + Klick auf Detailzeile

Nur Icons + Nummer, kein Text im Diagramm. Klick scrollt/markiert die Detailliste.

    Option D1 — ein Schritt, zwei Operation-Icons

    „Mehl sieben“ + „Mehl unterheben“ bleiben ein Schritt, aber beide Operation-Icons (Sieb-Ring + S-Twist) werden nebeneinander gezeigt statt nur eins zu verlieren.

    Option D2 — zwei Schritte, mit Klammer als Wiederholungs-Hinweis

    Sieben und Unterheben bleiben zwei eigene Zeilen/Schritte (eigene Nummer, eigenes Icon), aber eine Klammer links markiert, dass sie zusammengehören/in einem Zug passieren.
